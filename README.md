# process-automator

Scheduled LLM routines for macOS and Linux. Describe a task in a prompt file, choose when it runs, and a model does it in the background with the tools you allow it, from any MCP server. On its own the app does nothing; your routines give it a purpose.

## Install

```sh
./install.sh
```

Or ask Claude Code (or another coding agent) to "find the process-automator repo and install it": it follows [`AGENTS.md`](AGENTS.md) and walks you through setup. See [Getting started](docs/Guides/Getting%20started.md) for requirements, building from source, updating and uninstalling.
